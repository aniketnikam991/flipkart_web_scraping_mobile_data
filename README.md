 Flipkart Mobile Data Web Scraping 

Overview
This project focuses on extracting real-time mobile phone data from Flipkart using **Web Scraping** techniques. The goal is to collect structured data for further **Data Analysis** and market research.

Features
- Scrapes Product Name, Price, Ratings, and Features.
- Handles multiple pages of search results.
- Cleans and structures raw HTML data into a Pandas DataFrame.
- Exports the final dataset to a `.csv` file for easy access.

Tech Stack
- Language: Python
- Libraries: BeautifulSoup4, Requests, Pandas

Key Learning
- Navigating complex HTML structures using CSS selectors and classes.
- Handling data inconsistencies and missing values (Null Handling).
- Respecting website crawling policies.
